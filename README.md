# VTM Storyteller — Releases

Download page and update feed for **VTM Storyteller** (V20 AI Storyteller companion to Kindred Companion).
This repository holds only release binaries — no source code.

- Android: `VTM-Storyteller-<version>.apk`
- Windows: `VTM-Storyteller-<version>-Setup.exe`

Each file has a matching `.sha256`. Latest: https://github.com/UnboundRP/VTM-Storyteller-Releases/releases/latest
